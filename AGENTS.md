# Notes for AI agents

Read `README.md` first: what the site is, the commands, where the data lives. This file is what
isn't obvious from it.

## Before you call a task done

1. `npm run check` — no type errors.
2. `npm run verify` — every check `ok`. It needs Chrome installed; it starts and stops its own
   server on port 4329.
3. If you changed something visible, look at it: the dev server (`npm run dev`, port 4321) on a
   phone width (375) and a desktop width (1440), in both themes.

Say what you checked and what you couldn't (sound, touch, real phones).

## Layout of the code

| Where | What |
|---|---|
| `src/data/` | All texts and facts. Change content here, not in the pages. |
| `src/pages/index.astro`, `projects.astro` | The two pages; page-specific styles and scripts sit in each file. |
| `src/components/` | `SiteHeader` (the bar, shared), `SiteFooter`, `ThemeToggle`, `QuickContacts`, `TvScene` (the TV's markup, caption and wiring). |
| `src/scenes/` | Three.js: `crt-tv.ts` (scene, channels, knob, clicks), `crt-screen.ts` (picture shader), `channel-video.ts` (chunked video), `screen-glow.ts`, `knob-click.ts` (sound). |
| `src/styles/global.css` | Colour tokens for both themes, fonts, `--gutter`, `--bar-height`. |
| `scripts/` | Video and model preparation, `verify.mjs`. |
| `public/models/`, `public/video/<name>/`, `public/shots/`, `src/data/shots.json` | Generated by `npm run model` / `npm run video` / `npm run shots`. Don't edit. |

`3d/`, `videos/`, `screenshots/`, `CVs/`, `mockup/` and `.claude/` are local working files, ignored by git.

## Rules that are easy to break

- **Colours only through the tokens** in `global.css` (`--bg`, `--fg`, `--muted`, `--faint`,
  `--line`, `--accent`). Both themes must work: the dark one by default, the light one under
  `[data-theme="light"]` and under `prefers-color-scheme: light`. A new colour needs a value in both.
- **The bar's height is `--bar-height`.** Anything pinned under the bar uses it; don't hard-code 60px.
- **The bar is one component** (`SiteHeader`) on both pages and must sit in the same place on both
  (verify checks it).
- **The TV on Projects** (`TvScene` with `pageDriven="(min-width: 1025px)"`):
  - wide screens: the page picks the channel from the scroll position (`tv:select`), the TV reports
    what's on (`tv:channel`), a click opens the trailer, there's no "next";
  - narrow screens: the TV is on its own like on the home page — a click switches, channels without
    a video (projects under NDA) are left out, scrolling doesn't touch it, nothing is highlighted.
  - Events speak project indices; `TvScene` maps them to its own channels through `kept`.
  - Galleries: on wide screens with a mouse, the screenshot under the cursor goes on the TV
    (`tv:image`) and a click opens `Lightbox`, flying out of the TV's screen (`tv:rect`). On phones
    the TV isn't involved: a tap opens the viewer from the thumbnail.
  - Only the small previews (`*-thumb.webp`) load with the page; the TV uses them too. A full-size
    screenshot loads only when it's opened in the viewer, over its blurred preview.
- **Projects under NDA** have no `video`, `link` or real name: the title describes the game.
  Never add details that would identify them.
- **Knob and click area** are tuned to the model: `KNOB_UP`, `KNOB_DETENT` and `BODY_BOX` in
  `crt-tv.ts`. Changing the model means checking these again.
- **Facts about Dmytro come only from him** (or the CV in `CVs/`). Don't invent numbers, dates,
  companies or results; leave a visible placeholder and say so.

## Style

- Comments say why, in plain words, and sit above the line they explain. Match the density of the
  file you're in; most lines have none.
- Prefer CSS over JS for layout and states; JS toggles a class, CSS does the rest.
- No new dependencies without a reason worth stating.
- Page text is English.

## Common tasks

**Add a game.** Add an entry to `projects` in `src/data/projects.ts` (newest first). Screenshots:
put the originals into `screenshots/<name>/` (any size, png/jpg/webp, shown in the order of their
names; `cover.*` is the still on the trailer's tile), run `npm run shots`, set
`gallery: shots('<name>')`. If it has a clip:
put `<name>.mp4` (320×240, no sound) into `public/video/`, set `video: '/video/<name>.mp4'`, run
`npm run video`. The TV channels on both pages follow from the data. Run verify: the channel count
checks change with it.

**Change a text** on the home page: `src/data/profile.ts`, or the About paragraph in
`src/pages/index.astro`. Keep `#links` pointing at sections that exist (verify checks).

**Change a colour**: the token in `global.css`, in all three blocks that define it: `:root` (dark), `[data-theme="light"]` and the `prefers-color-scheme: light` one.

**Change the Open Graph image** (`public/og.png`): a 1200×630 screenshot of the home page top in the
dark theme, without the theme switch.
